# ADCC QS Register

Document register for Al Adeeb Building Contracting LLC — payments/IPAs, tenders, measurement sheets, variations, RFIs and NCRs, with status and "currently with" tracking.

- `www/` — the app (HTML/JS), backed by Supabase (login, database, file storage)
- `android/` — Capacitor Android project
- `.github/workflows/build-apk.yml` — builds the APK on every push to `main` and publishes it under **Releases**

## Install on Android
Open the latest release on GitHub from your phone, download `ADCC-QS-Register.apk`, open it and allow "Install unknown apps" when asked.
